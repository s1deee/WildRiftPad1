# WildRiftPad

Приложение для Android, которое превращает кнопки и стики геймпада в касания экрана
и позволяет играть в League of Legends: Wild Rift с геймпадом. Под телефон iQOO Neo10
и геймпад GameSir G7 Pro, но должно работать с любым Xbox-подобным геймпадом.

> Проект написан, но не собирался и не запускался. Вероятны мелкие ошибки компиляции
> и настройки, их нужно поправить при первой сборке.

## Как это работает

- **Служба спец. возможностей** перехватывает кнопки геймпада (`onKeyEvent`) и не пускает их в игру.
- Для каждой кнопки задана точка на экране. Нажатие кнопки превращается в касание этой точки.
- **Левый стик** ведёт палец от центра джойстика движения (касание держится, пока стик отклонён).
- **Правый стик** смещает палец вокруг удерживаемого навыка: держите навык, двигайте стик,
  отпустите кнопку для каста. Так работает прицеливание.
- Касания отправляются через `dispatchGesture` короткими кусками, все удерживаемые пальцы вместе
  (система выполняет только один жест за раз).

## Сборка

1. Установите Android Studio и откройте папку `WildRiftPad`.
2. Дождитесь синхронизации Gradle (понадобится интернет, он скачает Android SDK 34).
3. Build → Build APK(s), либо подключите телефон и нажмите Run.
4. Либо из консоли: `gradle assembleDebug`. Файл будет в `app/build/outputs/apk/debug/`.

## Первый запуск на телефоне

1. Установите APK и откройте WildRiftPad.
2. Нажмите «Включить службу в спец. возможностях» и включите WildRiftPad.
   Если пункт серый: «О приложении» → меню ⋮ → «Разрешить ограниченные настройки»,
   потом включите службу снова.
3. Разрешите приложению работать в фоне, без ограничений батареи и с автозапуском
   (на iQOO/OriginOS это настройки батареи и фоновой активности).
4. Подключите геймпад, откройте Wild Rift, зайдите в тренировку.
5. Нажмите на геймпаде **Select + Start** (или кнопку «Редактор» в приложении), совместите кружки
   с кнопками HUD, нажмите «Готово». Повторный Select + Start сохраняет и закрывает редактор.

## Раскладка по умолчанию

| Геймпад | Действие |
|---|---|
| Левый стик | Движение |
| Правый стик | Прицеливание удерживаемого навыка |
| R2 | Атака |
| A / X / Y / B | Навыки 1 / 2 / 3 / ульта |
| R1 / L1 | Заклинания призывателя |
| L2 | Возврат |
| R3 | Выбор цели |
| L3 | Сигнал |
| Крестовина | Магазин и предметы |

Стартовые координаты примерные, подгоните их под свой HUD в редакторе.

## Если что-то не работает

- **Кнопки не реагируют.** Откройте главный экран приложения, нажимайте кнопки геймпада и смотрите
  строку «Последнее событие геймпада». Если там пусто, служба не получает события.
- **Стики не реагируют, а кнопки да.** Движение стиков принимается только на Android 14 и новее.
  Если геймпад отдаёт правый стик не через оси Z/RZ или RX/RY, прицеливание не заработает.
  Пришлите, что показывает строка с осями.
- **Работает не в той игре или не работает в игре.** Включите «Работать в любом приложении».
  По умолчанию раскладка включается только для пакетов `com.riotgames.league.wildrift*`
  и `com.tencent.lolm`. Если у вас другая версия игры, поправьте `isGamePackage` в `PadService.kt`.
- **Касания запаздывают или обрываются.** Поиграйте со слайдером «Длина куска касания»
  (меньше: отзывчивее, но нагрузка выше).

## Важно

Это автоматизация ввода. Правила Riot Games могут запрещать такие инструменты,
поэтому есть риск блокировки аккаунта. Использовать на свой страх и риск, лучше сначала на запасном аккаунте.
